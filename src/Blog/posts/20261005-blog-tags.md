# Blog Tags

Blog posts on my website now have tags to help filter them! You can see the
tags for each post at the bottom of the page. On the blog index page, each
post's tags are shown in the upper right corner of the post's excerpt.

In addition to adding some color to the output and making things look more
interesting, the tags can also be used to filter the list of blog posts. For
example, [/Blog?tag=website][blog-tag-filtered] filters for blog posts that are
tagged as being related to my website. The tags shown at the bottom of each post
and in the excerpts are links that apply the corresponding filters. You can
hover over the tags to see descriptions of each.

This is my 31st blog post on this site, so having some method of organization
was starting to feel necessary. But I did not want to go overboard - at the
moment, the filtering is just a simple check of whether a post has a tag. At
some point I might add support for excluding posts with a given tag, or
filtering for posts that are tagged with one of a number of tags, or something
else, but a simple "Only show posts with tag ---" should be enough for now.

The filtering is currently implemented on the backend before the list of
excerpts is shown, but since I don't have any public examples of a single-page
application that I've written, I might switch to a dynamic version of the
filtering at some point, to showcase some ~fancy~ JavaScript. We'll see.

[blog-tag-filtered]: /Blog?tag=website
