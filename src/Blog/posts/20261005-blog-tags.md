# Blog Tags

Blog posts on my website now have tags to help filter them! You can see the
tags for each post on the bottom of the page, and on the blog index page the
tags are shown in the upper left corner of the post's excerpt.

In addition to adding some color to the output and making things look more
interesting, the tags can also be used as filters on the list of overall blog
posts. For example, [/Blog?tag=website][blog-tag-filtered] filters for blog
posts that are tagged as being related to my website. The tags shown on the
bottom of each post and in the excerpts are links that apply the applicable
filters. You can hover over the tags to see descriptions of each.

This is my 31st blog post on this site, so having some method of organization
was starting to feel needed. But, I did not want to go overboard - at the
moment, the filtering is just a binary check of if a post has a tag or not. At
some point I might add support for excluding posts with a given tag, or filtering
for posts that are tagged with one of a number of tags, or something else, but
a simple "Only show posts with tag ---" should be enough for now.

The filtering is currently implement on the backend before the list of excerpts
is shown, but since I don't have any public examples of single single page
applications that I've written, I might switch to a dynamic version of filtering
at some point, to showcase some ~fancy~ JavaScript. We'll see.

[blog-tag-filtered]: /Blog?tag=website
