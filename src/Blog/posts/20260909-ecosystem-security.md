# Joining the PHP Ecosystem Security Team

I'm excited to share that I am joining the PHP Foundation's Ecosystem Security
Team to help harden the PHP codebase.

As AI tools generate more and more security reports, they frequently report
issues that the PHP project does not consider to be security vulnerabilities,
but which are still worth addressing as code hardening measures. Other times,
the AI agents simply don't understand something because it isn't documented
well. In those cases, the solution is to improve the documentation, benefiting
both AI agents and regular PHP developers. More details about this work are
available [on the PHP Foundation blog][phpf-blog].

I've only just begun, but I've found the work so far to be fascinating, giving
me a chance to work on parts of the PHP codebase that I'm not very familiar
with.

I now contribute to PHP wearing three different "hats":

* as a volunteer developer, maintaining the Reflection extension, implementing
new features, addressing bugs, etc.
* as a release manager, building and releasing new versions of the PHP 8.5
branch
* [new] as a contractor for the PHP Foundation Ecosystem Security Team, helping
address non-security issues that are reported to the security team and qualify
as hardening

I look forward to helping secure the PHP project moving forward.
